Política de privacidad

Aula Sin Fronteras — Traducción en vivo con IA · Junio de 2026

Resumen

Aula Sin Fronteras no recopila, almacena ni vende ningún dato personal. No hay cuentas, ni servidores propios, ni analítica, ni publicidad. Todo el procesamiento ocurre en el navegador del usuario.

Qué hace la extensión

Transcribe la voz del profesor durante una clase y muestra su traducción en tiempo real a otro idioma, para que el alumnado que no domina el español pueda seguir la lección.

Micrófono

El micrófono se activa solo cuando el usuario pulsa «Iniciar» y se usa exclusivamente para el reconocimiento de voz mediante la Web Speech API del navegador. El audio no se graba, no se almacena y no se envía a servidores propios. Al pulsar «Detener» se desactiva.

Datos que se procesan

  • Voz: procesada por la Web Speech API de Chrome para convertirla en texto.
  • Texto transcrito: se envía a la API pública de Google Translate solo para obtener su traducción, sin asociarse a ninguna identidad.
  • Funciones opcionales: los botones «IA» y «Email» copian texto al portapapeles y abren Gemini, ChatGPT o Gmail en una pestaña nueva. Es el usuario quien decide pegar y enviar.

Qué NO hacemos

  • No recopilamos datos personales ni identificadores.
  • No usamos cookies, analítica ni rastreadores.
  • No vendemos ni compartimos información con terceros.
  • No almacenamos las transcripciones: desaparecen al cerrar la página.

Permisos

La extensión no solicita permisos especiales de Chrome. El permiso de micrófono lo concede el usuario directamente en la página.

Menores

La extensión está pensada para uso docente y no recopila información de ningún usuario, incluidos menores.
